# TidyMac Windows — OpenCode Agents & Skills

## Project agents (custom commands)

Use these agents by typing `@<name>` in the OpenCode prompt:

| Agent | Purpose |
|-------|---------|
| `@next` | Find and plan the highest-priority Phase 7 feature from NEXT-STEPS.md |
| `@discover` | Find candidate features & enhancements across gaps, specs, ideas, & competitors |
| `@implement <feature>` | Full TDD implementation workflow (register → test → implement → validate → docs) |
| `@validate` | Run `cargo test --workspace && bun run test`, report all results |
| `@safety-check` | Audit code for TidyMac Windows safety invariants |
| `@windows-spec` | Look up implementation map and spec links |
| `@windows-feature-spec` | Research a specific feature spec before implementing |
| `@windows-mcp-triage` | Triage MCP tool issues |
