# ClipForge Filters Pack

This branch contains **49 production-ready color grading filters and 3D Hald CLUTs**.

Each filter includes:
- `filter.png`: Standard 512x512 Level-8 Hald CLUT (compatible with FFmpeg haldclut filter).
- `manifest.json`: Metadata, parameter ranges, and default values.
- `AmazingFeature/`: Raw GLSL fragment and vertex shaders with optical effects.
- `.verified`: Cryptographic verification hash.
